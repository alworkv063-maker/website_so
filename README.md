# Макет сайта · ТД «Солярис»

Статический макет: `index.html`, `prices.html`, стили и скрипты в `assets/`.

## Форма заявок — настройка за 1 минуту

Заявка с сайта («Оформить заказ / заказать звонок») приходит письмом на
**sales@solaris-samara.ru**. Работает через бесплатный сервис
[Web3Forms](https://web3forms.com) — без Google-таблиц, без своего сервера,
без регистрации аккаунта.

Пока это не сделано, форма работает запасным способом: при отправке
открывается почтовая программа с уже заполненным письмом на тот же адрес.

### Шаг 1. Получить ключ

**Важно:** регистрироваться нужно под почтой **sales@solaris-samara.ru**
(или другой рабочей почтой заказчика), а не под личной — иначе владельцем
формы в Web3Forms останетесь вы, а не заказчик, и после передачи сайта он
не сможет сам управлять приёмом заявок.

Открыть **[web3forms.com](https://web3forms.com)** — в режиме инкогнито
или предварительно выйдя из своего аккаунта, чтобы случайно не зайти под
личной почтой. Войти/зарегистрироваться под **sales@solaris-samara.ru**,
создать форму (Create Form): имя — любое, например «Заявки — Солярис»,
Website URL — `solaris-samara.ru`. После этого покажется ключ вида:

```
a1b2c3d4-e5f6-7890-abcd-ef1234567890
```

Скопировать его.

### Шаг 2. Вписать ключ в сайт

Открыть `assets/js/main.js`, самые первые строки:

```js
var WEB3FORMS_KEY = 'сюда вставить ключ из шага 1';
```

Сохранить файл. Всё — заявки с сайта пойдут на sales@solaris-samara.ru.

### Проверка

Открыть сайт, заполнить форму «Оформить заказ», отправить — письмо должно
прийти в течение минуты (проверьте папку «Спам», если не видно).

### Лимит

Бесплатный тариф Web3Forms — 250 писем в месяц, для заявок с сайта этого
с большим запасом достаточно.
